# Gemini 보고서 도우미 설정

프로젝트 루트의 `.env.local`에 다음 값을 추가하세요. 기존 Supabase 설정은 유지하세요.

```dotenv
GEMINI_API_KEY=발급받은_Gemini_API_키
GEMINI_MODEL=gemini-2.5-flash
AI_CHAT_PASSWORD=관리자가_정한_긴_이용_암호
```

- [Google AI Studio](https://aistudio.google.com/apikey)에서 API 키를 발급받습니다.
- 키와 이용 암호에 `NEXT_PUBLIC_` 접두사를 붙이지 마세요. `.env.local`은 Git에서 제외됩니다.
- 개발 서버를 재시작합니다: `npm run dev`.
- 배포 시 호스팅 서비스에도 같은 서버 환경변수를 등록하고 다시 배포합니다.

## 사용

학생을 선택하면 오른쪽 아래에 파란 채팅 아이콘이 나타납니다. 패널에서 이용 암호를 입력하고 요청을 전송하세요. 처음에는 대화만 가능하며, **AI의 현재 보고서 수정 허용**을 켜면 과목·교재·진도·과제·전달사항을 수정할 수 있습니다.

AI 수정은 일괄 편집 모드에서도 현재 학생 한 명에게만 적용됩니다. 변경 후 기존 **보고서 저장** 버튼으로 저장하세요. 마지막 AI 수정은 **수정 되돌리기**로 복구할 수 있으며, 그 이후에 보고서가 바뀌었다면 덮어쓰지 않습니다. 학생이나 날짜를 바꾸면 대화와 권한이 초기화되고 진행 중인 요청은 취소됩니다.

클립 아이콘으로 이미지(JPEG, PNG, WebP, HEIC/HEIF), PDF, 텍스트, Markdown, CSV, JSON을 최대 3개까지 첨부할 수 있습니다. 첨부파일 전체 용량은 3MB로 제한됩니다. Gemini는 첨부 내용을 분석하거나 OCR하고, **AI의 현재 보고서 수정 허용**이 켜져 있으면 그 내용을 바탕으로 현재 보고서의 편집 가능한 항목을 수정할 수 있습니다. 원본 첨부파일 자체를 덮어쓰지는 않습니다.

Gemini에는 학년과 편집 가능한 학습 내용, 최근 대화가 전달됩니다. 이름·교사·학생 ID는 보고서 문맥에서 제외하지만 학습 내용이나 사용자가 입력한 대화에 직접 적힌 개인정보는 전달될 수 있습니다. 대화와 이용 암호는 브라우저 메모리에만 유지됩니다.

## 운영 및 확인

현재 앱에는 사용자 로그인/역할 관리가 없습니다. AI API는 별도 이용 암호로 보호하며, 보고서 DB에 직접 접근하지 않고 열린 편집 화면에만 변경안을 반환합니다. 이는 학생별 접근 권한을 검증하는 로그인 시스템을 대체하지 않습니다.

서버 인스턴스마다 분당 20회, 동시 3회로 요청을 제한합니다. 여러 인스턴스의 통합 한도는 아니므로 공개 운영 시 Gemini 프로젝트 할당량과 비용을 별도로 관리하세요. 요청은 45초 후 중단됩니다.

키가 없으면 설정 안내를 표시합니다. 잘못된 이용 암호, 잘못된 응답, 사용량 초과 또는 네트워크 오류에서는 보고서를 변경하지 않습니다. 실제 Gemini 연결은 유효한 API 키를 설정한 뒤 확인해야 합니다.

구현 참고: [Gemini 구조화된 출력 공식 문서](https://ai.google.dev/gemini-api/docs/generate-content/structured-output).
