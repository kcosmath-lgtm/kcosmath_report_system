# COSMATH 학습 성장 보고서 구성안

## 디자인 방향

- 크림색 종이 배경(#FAF9F5), 짙은 초록색 제목과 그래프(#28654F), 연한 세이지색 보조 영역(#DCE9E1).
- 본문은 먹색, 미완료는 차분한 벽돌색으로 표현한다. 모든 상태에 글자와 수치를 함께 표시한다.
- 장식보다 숫자와 기록을 중심으로 구성한다. 작은 영문 보조 제목, 짧은 가로선, 여백과 얇은 테두리를 사용한다.
- 화면에서는 한 열로 읽고, PDF에서는 A4 세로 3장으로 구분한다. 긴 교재 목록과 기록은 잘리지 않게 추가 페이지로 넘긴다.

## 1장: 이번 달 한눈에

상단: COSMATH / 학생 이름 / 반·학년 / 집계 기간 / 실제 기록일 수.

요약 카드 네 개: 출석 일수, 숙제 완료율, 오답 완료 실천율, 수정한 오답 수.

본문: 날짜별 오답 수·수정 수 막대그래프, 출석·숙제·오답 실천 달력.

하단: 교사가 직접 작성하는 이번 달 요약과 다음 달 목표.

## 2장: 교재와 단원 성장

교재마다 다음 내용을 한 묶음으로 표시한다.

- 교재명과 과정.
- 기간 시작 전 마지막 저장 진도 → 기간 종료일까지 마지막 저장 진도.
- 페이지 기준 또는 단원 완료 기준을 적은 진행률 막대.
- 기간 내 새로 완료한 단원과 현재 진행 중인 단원.
- 최근 내준 숙제와 제출 예정일(기록된 경우).

기준일의 저장 스냅샷을 사용한다. 현재 교재 설정으로 과거 보고서의 단원명이나 총 페이지를 덮어쓰지 않는다. 시작 전 기록이 없으면 시작 진도는 '기준 기록 없음'으로 표시한다. 기간 내 기록이 없는 교재는 별도로 표시한다.

## 3장: 실천과 선생님 피드백

숙제 완료·일부 완료·미완료 일수와 오답 완료 실천율을 큰 수치와 막대로 표시한다.

날짜별 표: 날짜 / 출석 / 오답 전체·수정 / 숙제 상태 / 비고.

하단: 잘한 점 / 보완할 점 / 다음 학습 계획. 수업 비고는 내부 기록으로 취급하고, 보고서에 포함할 내용은 교사가 미리보기에서 선택한다.

## 집계 원칙

- 출석은 기록된 출석·지각·결석·조퇴 일수로 표시한다. 예정 수업일이 없으므로 출석률은 계산하지 않는다.
- 숙제 완료율 = O 일수 ÷ 상태가 기록된 일수(O·△·X). 일부 완료를 임의로 0.5로 환산하지 않는다.
- 오답 완료 실천율은 오답 수량이 있거나 명시적으로 완료 표시한 날을 기준으로 한다.
- 오답 수정률은 수정 문제 수 ÷ 전체 오답 수다. 수량 없는 완료일은 문제 수에 보태지 않는다.
- 기록이 없으면 0% 대신 '미기록' 또는 '계산 대상 없음'으로 표시한다.
- 학습 시간·계획 달성률·학년 평균 비교는 현재 원천 데이터가 없으므로 넣지 않는다.
- 서로 다른 교재의 진행률을 단순 평균해 학생의 전체 성취도로 표현하지 않는다.

## 구현 순서

1. 기존 보고서 경로는 유지하고 '학습 성장 보고서'를 별도 양식으로 추가한다.
2. 학생·기간 선택 후 출결·오답·숙제와 교재 진도 스냅샷을 모아 동일한 집계 결과를 화면과 PDF에 사용한다.
3. 교사 코멘트를 입력하고, 포함할 비고를 선택해 미리보기한다. 코멘트 저장은 별도 데이터 구조가 필요하다.
4. PDF 인쇄를 먼저 지원한다. 이후 같은 집계 결과로 페이지별 이미지 다운로드를 추가한다.
5. 기간 집계·미기록 처리·과거 진도 스냅샷과 A4 페이지 넘김을 검증한다.
