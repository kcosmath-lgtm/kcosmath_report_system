# 수학 기출 수집

EBSi 공식 기출 자료실의 고1·고2·고3 수학 목록을 수집한다. 현재 검색 범위는 공식 자료실에서 제공하는 2006~2026년이다. 수능·모의평가·학력평가 및 선택과목별 자료가 포함되므로 목록 건수는 시험 시행 횟수와 다르다.

- 목록: `src/data/mock-exams.json`
- 원본: `public/question-bank/files/`
- 수집 캐시: `.local-backups/mock-exams/` (Git 제외)
- 화면: `/question-bank`

```powershell
node scripts/import-mock-exams.mjs --download
```

이미 저장된 자료는 재사용한다. 목록까지 새로 확인하려면 `--refresh`를 추가한다. `--download` 없이 실행하면 목록만 갱신하고 기존 다운로드 정보를 유지한다. 수집 범위의 마지막 연도는 스크립트에서 명시적으로 관리한다.

PDF·정답 이미지를 원본 그대로 보관한다. SHA-256이 같은 파일은 한 번만 저장하고 여러 자료에서 공유한다. 다운로드 응답의 파일 형식을 검사하고, 실패한 자료는 오류를 목록에 기록한다. 화면은 로컬 파일을 확보한 자료에만 문제·정답·해설 버튼을 제공한다. 공식 자료실 링크는 학년별 목록으로 연결된다.

`node --test tests/mock-exams.test.cjs`로 학년별 수집 건수와 저장 파일의 크기·해시를 검증한다.

현재는 시험지 단위의 자료실이다. 문항별 좌표·텍스트 추출, AI 변형, 문항 조합 기능은 포함하지 않는다. 파일은 프로젝트의 정적 자료이며 Supabase에 업로드하지 않는다. 다른 환경에서 사용하려면 목록과 원본 파일을 함께 전달해야 한다. 향후 파일 저장소로 옮길 때에는 해시를 저장 키로 유지할 수 있다.
