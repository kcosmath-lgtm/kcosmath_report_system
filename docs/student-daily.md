# 학생 날짜별 기록

기본 표는 출석·오답·숙제로 구성됩니다. 표의 체크박스로 학생을 선택하면 항목별 일괄 적용 도구가 나타나며 적용 후 수업 기록 저장을 눌러야 저장됩니다. 날짜 선택과 저장 버튼은 같은 높이입니다.

성적 엑셀 가져오기는 배정문제지 목록의 HTML 기반 `.xls`를 지원합니다. 실제 바이너리 XLS/XLSX는 아직 지원하지 않습니다. 학생명·학년·반으로 자동 연결하고 미확정 학생은 직접 연결합니다. 생성일을 시험 날짜로, 점수를 100점 만점으로 미리 표시하며 날짜를 수정할 수 있습니다. 미채점은 제외합니다. 학생/날짜/문제지ID가 같은 성적은 다시 추가하지 않습니다. 출석·오답·숙제 기존 기록은 그대로 두며 성적만 추가합니다. 성적 보기 버튼에서 선택한 학생들의 해당 월 성적을 조회합니다. 학생 선택이 없으면 해당 월 전체 성적을 표시합니다. 기존 성적의 수정은 학생 상세에서 가능합니다.

학생 관리의 왼쪽 목록에서 반 또는 학생을 선택하면 기존 프로필 카드 대신 수업 기록 표가 열립니다. 출석과 숙제의 신규 기록 기본값은 출석·완료이며 저장을 눌러야 실제로 누적됩니다. 기존 저장된 미기록·결석·미완료 값은 유지됩니다. 표에서 전체 오답과 완료 오답 개수를 입력합니다. 학생 이름 또는 성적 입력을 누르면 상세 영역에서 사유와 시험 성적을 작성합니다. 저장은 수정한 학생과 현재 선택된 학생의 신규 기본값을 함께 반영합니다.

학생 옆 연필 버튼에서 이름·학년을 수정하고 휴지통 버튼에서 영구 삭제합니다. 학생 편집 기능은 `supabase/migrations/202610090002_edit_student.sql`도 적용해야 합니다. 오답·숙제 보고서 버튼은 학생 관리 상단에 있으며 기존 `/errors` 주소는 학생 관리로 이동합니다.

운영 배포 전 Supabase SQL Editor에서 `supabase/migrations/202610090001_student_daily_records.sql`을 적용해야 합니다. 기존 오답·숙제 마이그레이션이 적용되어 있어야 합니다. 개발 환경에서는 IndexedDB 버전 4로 자동 업그레이드됩니다.

오답·숙제는 기존 `cosmath_wrong_answers`를 공유합니다. 출석·성적은 `cosmath_student_daily_records`에 학생/날짜별로 저장되며 날짜를 바꾸어 저장해도 이전 기록이 유지됩니다. 동일 날짜의 수정은 버전 충돌을 검사합니다. 출석·성적과 오답·숙제는 단일 트랜잭션으로 저장합니다. 재원생·학원 권한을 서버에서 검사합니다.

시험 없는 날은 시험을 추가하지 않습니다. 미기록 출석은 결석으로 취급하지 않습니다. 시험 점수는 만점과 함께 보관합니다. 이번 달 기록 이력에서 날짜를 다시 열어 수정할 수 있으며 다른 달은 날짜 선택으로 조회합니다.

현재 숙제는 기존 날짜별 상태 기록입니다. 과제별 제출 기한·완료 시점, 미완료 과제 자동 이월, 예정 수업 기반 출석률, 통계 그래프 및 보고서 자동 반영은 후속 기능입니다.
